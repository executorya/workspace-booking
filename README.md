# WorkSpace Booking

Учебная fullstack-платформа для бронирования рабочих пространств и помещений.

## Возможности

- регистрация и вход пользователей;
- роли `USER` и `ADMIN`;
- каталог рабочих мест, переговорных и конференц-залов;
- фильтрация по типу, вместимости, цене и дате;
- интерактивная схема пространства с выбором конкретного места;
- подсветка свободных, выбранных и занятых мест по выбранным дате и времени;
- создание бронирований с проверкой пересечения по месту и времени;
- личный кабинет пользователя со списком бронирований;
- админ-панель для управления помещениями и статусами бронирований.

## Стек

- Frontend: React, TypeScript, Vite;
- Backend: Node.js, Express, TypeScript;
- Database: SQLite;
- Auth: JWT + bcrypt.

SQLite выбрана для удобного локального запуска без отдельного сервера базы данных.

## Запуск

```bash
npm install
npm run db:seed
npm run dev
```

Frontend: http://localhost:5173  
Backend: http://localhost:4000
